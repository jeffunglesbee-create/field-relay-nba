## CONTEXT

Two gaps in the brief archive pipeline:

1. KV sweep (brief:game:* → D1 briefs table) only runs during
   dead hours (UTC 2:00-10:00). Per-game briefs are written to KV
   during LIVE hours with a 1h TTL. The sweep can miss briefs
   that expire before the next dead-hour tick. Current state:
   41 game_recap rows for June 21, but only 17 came from kv_capture
   (reactive, on /archive/game request). The other 24 from cron
   (queue consumer writes both KV + D1). Briefs generated by the
   live-hour journalism cycle that go to KV only (lines ~2715, ~2810)
   are at risk of TTL expiry without D1 capture.

2. game_brief backfill (per-game LLM-generated briefs for completed
   games) only fires when briefResult.skipped === true (slate brief
   already exists for the date). For recent dates where the slate
   brief was generated LIVE by the cron, skipped is false and the
   game brief backfill never triggers. Result: zero game_brief rows
   exist for any date after June 17.

```javascript
// Extract KV sweep into a standalone function
async function sweepKVBriefs(env) {
    if (!env.FIELD_JOURNALISM || !env.ARCHIVE_DB) return null;
    await ensureBriefsTable(env);
    const listed = await env.FIELD_JOURNALISM.list({ prefix: 'brief:game:', limit: 50 });
    let swept = 0;
    for (const key of (listed.keys || [])) {
        const kvVal = await env.FIELD_JOURNALISM.get(key.name).catch(() => null);
        if (!kvVal) continue;
        let briefText = kvVal;
        let qualityScore = null;
        if (kvVal[0] === '{') {
            try {
                const p = JSON.parse(kvVal);
                briefText = p.brief || p.brief_text || p.text || kvVal;
                qualityScore = p.quality_score || p.score || null;
            } catch(_) {}
        }
        if (!briefText || briefText.length < 50) continue;
        const parts = key.name.replace('brief:game:', '').split(':');
        const gameId = parts.length >= 2 ? parts[parts.length - 1] : parts[0];
        const sport  = parts.length >= 2 ? parts[0] : null;
        if (!sport) {
            const existing = await env.ARCHIVE_DB.prepare(
                `SELECT 1 FROM briefs WHERE game_id = ? AND sport IS NOT NULL AND sport != '' LIMIT 1`
            ).bind(gameId).first().catch(() => null);
            if (existing) continue;
        }
        const sweepDate = new Date().toISOString().slice(0, 10);
        await env.ARCHIVE_DB.prepare(
            `INSERT INTO briefs
               (id, date, brief_type, sport, game_id, brief_text, quality_score, word_count, source)
             VALUES (?, ?, 'game_recap', ?, ?, ?, ?, ?, 'kv_sweep')
             ON CONFLICT(id) DO NOTHING`
        ).bind(
            `game_recap_${gameId}_${sweepDate}`,
            sweepDate, sport, gameId, briefText, qualityScore,
            briefText.split(/\s+/).length
        ).run();
        swept++;
    }
    return swept > 0 ? { swept } : null;
}
```

## TASK 2: Fix game_brief backfill gate

File: src/index.js, ~line 4868

Current condition:
```javascript
if (env.ARCHIVE_DB && nextDate && briefResult && briefResult.skipped) {
    gameBriefResult = await executeGameBriefBackfill(env, nextDate);
}
```

This only fires when the slate brief was already present (skipped=true).
For recent dates, the slate brief was just generated live, so
skipped is never true.

Change the condition to also fire when the slate brief was just
written successfully (briefResult.ok === true):

```javascript
if (env.ARCHIVE_DB && nextDate && briefResult
    && (briefResult.skipped || briefResult.ok)) {
    gameBriefResult = await executeGameBriefBackfill(env, nextDate);
}
```

This means: "if we have a date with a slate brief (whether
pre-existing or just written), try to generate per-game briefs."
The executeGameBriefBackfill function already deduplicates
internally (checks for existing game_brief rows before generating).
