**How A is built so that it can be wrong safely.** (1) Pull only, one cached read per request, never a push (ADR-002 Rule A). (2) An upstream failure, or a status the adapter has not been shown, is a named 502, never an empty slate and never a guess (the NBA board's lesson, `CC-CMD-2026-10-22-nba-cdn-403-in-season`). (3) Stage 1 maps only what was read: `SCHEDULED` is `pre`, `CONCLUDED` is `final`. Stage 2 adds the live spelling from the Grand Final capture itself, the first time it can be read. (4) The whole dependency is one `V2_LEAGUES` key, one adapter and one archive writer; if the owner's reading of the quoted terms says otherwise, removing it is a revert of those three, and nothing else reads aflapi.
