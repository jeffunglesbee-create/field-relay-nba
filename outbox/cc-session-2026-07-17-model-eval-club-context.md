## Production Change: Club-Context Convention

`FIELD_VOICE_REGISTER` in `src/journalism-quality.js` updated (commit fa40dc5)
to add explicit guidance after Exemplar D:

- Include club affiliation on first mention of each goalscorer in international
  soccer briefs (WC, Euros, Copa América, Nations League)
- Embed naturally in prose: "the Bournemouth striker Ueda" or "Kamada (Crystal Palace)"
- One club reference per player, then name only
- Do not list clubs parenthetically at end — weave into the action

This is a production change that affects every international soccer brief
generated by the journalism pipeline. Haiku 4.5 correctly applied it on first
run with no additional prompting.

## Verdict

**GPT-4o mini: not viable.** Ignores club context entirely. Cannot escape
press-release register regardless of system message or temperature.

**GPT-4.1 nano: partial improvement, not sufficient.**
- Follows club-data instruction better than 4o mini — affiliations appear
- Form is wrong: "Kamada from Crystal Palace" reads like a team sheet, not
  broadcast prose. Does not match the specified parenthetical convention.
- Still uses banned superlatives ("commanding," "dominant")
- ~3.5x cheaper than Haiku ($0.000036 vs $0.000125/brief) — not enough to
  justify the register quality gap for a fallback that must maintain FIELD voice

**Haiku 4.5: confirmed correct fallback.**
- Club context: correct form on first run, no additional prompting needed
- Narrative instinct: "the math gets real," "running out of oxygen" — voice
  that GPT-4.1 nano cannot produce
- Ongoing violation watch: efficiency/clinical phrasing appearing across both
  Haiku runs — worth adding explicit guidance to the register in a future prompt

## Key Lesson: Register Following Is a Model Property

FIELD_VOICE_REGISTER is 8,300+ chars of detailed style instruction with
4 exemplars, an anti-exemplar, and 6 grammar patterns. GPT-4o mini ignores it.
GPT-4.1 nano partially follows it (data instructions) but misses form conventions
and voice. Haiku 4.5 follows it — both instructions and register. This gap is
not closeable with better prompts for the OpenAI nano-tier models tested.
